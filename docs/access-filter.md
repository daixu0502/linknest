# 访问过滤

白名单优先于手动、自动和订阅名单。管理后台不受业务过滤影响。

## 自动与手动封禁

- 默认统计 60 秒内 20 次 HTTP 404，封禁 3600 秒。可以选择其他 4xx、统计窗口、触发次数、解除秒数和排除路径。默认忽略内网与保留地址。
- 排除路径每行一个；以 `/` 结尾时匹配前缀，其余精确匹配，不匹配查询参数。
- 手动永久名单支持 IPv4 / IPv6 或 CIDR；手动定时封禁只填单 IP，解除秒数 0 为永久，最长 30 天。
- 显示来源、原因、触发次数和解除时间，可单独解除或清空自动记录。解除会重置异常计数，但不会移除永久名单或订阅条目。
- 自动记录定期保存，正常停止刷新；异常断电最多丢失最近刷新周期的记录。保存过的解除时间在重启后保持原值，不延长封禁。

## 黑名单订阅

支持公开 HTTPS 地址，纯文本每行一个 IP / CIDR，允许 `#`、`;` 注释；另支持 Spamhaus JSON。各源独立更新、显示条目数、错误、最近成功及下次更新时间；失败保留该源最近成功名单。停用 / 删除立即退出过滤，删除清理该源缓存。

启用后调度约每 30 秒检查，更新间隔 1—720 小时；每源每小时最多请求一次，手动更新也受限，重启保留冷却时间。默认预设只添加停用配置，不会自动启用。

可用官方来源：[Spamhaus Project DROP](https://www.spamhaus.org/blocklists/do-not-route-or-peer/)。

- IPv4：`https://www.spamhaus.org/drop/drop_v4.json`
- IPv6：`https://www.spamhaus.org/drop/drop_v6.json`

DROP 是已知高风险网络，不是所有恶意单 IP 的全集，也可能影响正常访问。按上游要求署名 Spamhaus Project、保留原始文件中的版权和日期，不得每小时多于一次抓取。其他自定义订阅须自行核对许可和误报。

GeoIP 是地理位置数据库，不是威胁名单，不能直接导入此模块。订阅拒绝凭据、查询令牌、自定义端口及 HTTP；实际 DNS 解析和每次重定向均检查内网 / 回环 / 元数据 / 保留地址，不走环境代理。空名单、HTML 错误页、损坏或超限文件不会覆盖旧缓存。

## 范围

| 范围 | 永久手动名单 | 自动 / 定时封禁、订阅 | HTTP 异常统计 |
| --- | --- | --- | --- |
| 反向代理 | 支持 | 支持 | 支持 |
| 兼容 TCP / UDP | 支持 | 新连接 / 新数据包 | 不适用 |
| 内核 NAT | 支持 | 不适用 | 不适用 |
| 管理后台与路由器其他服务 | 不过滤 | 不过滤 | 不统计 |

只使用直接连接源地址，不信任 X-Forwarded-For。CDN / 前置代理后会看到代理 IP，可能误封整个出口；先设豁免并谨慎测试。不会踢掉已有 TCP / WebSocket 会话。

## 资源限制

最多 16 个订阅，每源 8 MiB / 50000 条，合计 200000 条；最多 5000 封禁、10000 个计数 IP / 50000 个异常事件，超限不继续添加。本功能不是 DDoS 防护。名单按 CIDR 前缀长度查表，不逐请求扫描所有条目。
