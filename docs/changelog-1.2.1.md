# LinkNest 1.2.1

- 登录和初始化页面从服务端读取版本；退出登录或会话失效后也保留正确版本，不再写死为 1.1.5。
- 切换页面和设置标签时保留侧栏节点、焦点与滚动位置。
- 外观、退出登录改为版本信息右侧的图标按钮，保留悬停说明和无障碍名称。
- 缩小菜单及分组间距，常见桌面和手机高度完整展示菜单；矮窗口仅滚动菜单，底部操作保持可见。
- 重新设计总览：运行摘要与待处理事项优先，提供服务列表、证书有效期、域名同步、连接安全和最近活动；指标与真实状态对应，可直达管理页面。
- 管理界面内嵌精简的中文无衬线字体，菜单采用常规字重，折叠标题采用中等字重。
- 折叠标题的悬停和焦点高亮沿用容器圆角；证书过程末行的焦点框不再被卡片裁切，申请说明与按钮之间增加间距。
- 页面内切换子标签只替换内容，保留大标题与状态栏，消除重复动画闪动。
- 标签栏统一为圆角分段控件，选中、悬停和键盘焦点保持相同轮廓。
- Go 更新到 1.26.10，x/crypto 更新到 v0.58.0，修复官方扫描识别的标准库和 SSH 调用路径漏洞；发布门禁增加 govulncheck，并核对两种架构最终二进制的编译器版本。
- 发布工具按当前版本选择验收目录，支持显式指定仓库代理，覆盖 Buildx 多架构标签操作。

配置 schema 保持 5。构建、双架构运行和界面验证继续在本机 WSL Docker 执行，验收后再替换路由器正式容器。
