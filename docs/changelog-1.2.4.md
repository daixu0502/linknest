# LinkNest 1.2.4

- 总览异常提示改用等距留白与同心圆角，悬停使用柔和底色，键盘焦点边框保持在高亮轮廓内。
- 未保存修改使用应用内确认框，默认继续编辑；取消或按 Esc 保留草稿、滚动位置和焦点。切换编辑器和页面也采用同一交互，过期确认不会影响新弹窗。关闭浏览器或刷新页面仍由浏览器提供离开保护。
- 设置页的配置导入导出、外观与帮助按钮成组对齐；窄屏自动换行，去除第二个按钮多余的左侧偏移。
- 规则状态筛选改用应用内下拉菜单；统一下拉箭头留白与菜单圆角，支持键盘选择并保留刷新期间的展开状态。普通按钮、图标按钮和下拉按钮共用柔和高亮与内置焦点边框，避免方角、双重描边和边缘裁切。

包含 1.2.3 的页面与标签动画调整。配置 schema 保持 5。
