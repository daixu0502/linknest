# LinkNest 1.2.0

- 配置保存增加版本保护，旧页面不会覆盖新配置；保存后串行应用，状态读取不等待防火墙操作。
- 修复 WebSocket 升级连接追踪泄漏，停用共享端口中的单条入口也会关闭对应连接。
- 外部反代子规则支持路径分流，同域名按最长路径段匹配，保留原路径、编码和查询参数；WS/WSS 使用同一路由。
- 多证书续期按到期时间排队，启动时检查，失败退避且不阻塞其他证书；当前证书信息与下次申请配置分开显示。
- Web 终端按登录会话撤销，退出、账号安全变更和停用功能会关闭连接；设备和 SSH 指纹检测不占用终端额度。
- UDP 新会话使用有界 DNS 缓存，双向流量均延长空闲时间，显示会话容量及丢弃计数。
- 防火墙 IPv4/IPv6 独立报告；规则区分监听、放行和后端检查，运行环境显示权限、内核表与转发能力。
- 页面按网络服务、常用工具、系统管理分组；增加搜索筛选、高级选项、移动端帮助、持续错误状态和冲突核对。轮询保留焦点、展开状态与草稿，旧请求不会关闭新弹窗。
- 更换 DDNS AccessKey ID 必须同时提供 Secret。完整备份改用停机后的 Docker 数据复制，独立验证恢复。
- 正式镜像保持 scratch 精简运行环境。发布增加 WSL Docker、ARM64 仿真、双栈内核流量和完整备份恢复验收；通过后才能替换路由器并发布。

## 配置接口变更

`GET /api/state` 返回 `configRevision` 和 `application`。`PUT /api/config` 必须把读取的版本原样放入 `If-Match`：缺失返回 428，过期返回 412，成功保存返回 202。202 表示配置已保存并排队，应用结果以 `application.state` 的 pending / applied / error 为准。发生冲突时重新读取并核对草稿，不自动重试覆盖。

配置 schema 升至 5，旧子规则路径默认 `/`。原规则启用状态、双地址族规则、原 IP 设置及加密凭据保持原值。1.1.5 回滚必须同时恢复升级前数据，不能直接读取 schema 5。
